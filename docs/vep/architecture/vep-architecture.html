What Building the Reference Page Taught Us

Hands-on evidence from migrating SAP Connect Day Houston, building the template, rolling out a second event, and the market-rollout PoC. Each lesson became a rule in the proposed architecture.

AreaWhat happened in the buildRule we propose
MigrationThe source site blocks direct fetches (403); scraping needed a real browser.Budget browser-based import tooling for SAP sources.
MigrationTracking pixels were imported as content and stretched the page by ~12,000px above the footer.Importer cleanup strips tracking and analytics markup before content lands in Experience Workspace.
Migration48 image URLs on the Houston page point at the POC host; some logo alt texts were mislabelled.Media is referenced by relative path; alt text is a QA checkpoint.
BlocksThe tabs block absorbed every following section of the page as tab panels.Complex components (agenda) live in their own fragment.
BlocksThe vendored form block needed a compatibility shim, a grid-layout override and a specific JSON envelope before it rendered.Third-party blocks get an adapter layer; Adobe's standard page engine stays untouched.
BlocksHeader/footer page settings didn't work as fragment paths, so event pages showed the wrong header and footer.Each event gets its own header/footer based on its URL, with a shared fallback.
DesignFirst pass used a dark theme; the source is light. Clipped intro, sponsor tiers, two-column form and floating labels each took rounds.Side-by-side visual check against the source is part of the definition of done.
TemplateThe blank template showed broken images and a fragment error in the Experience Workspace editor; Chicago's registration page was never created.Templates use text placeholders, and an "event kit" includes the child pages (registration).
PublishingPages published before their header/footer fragments showed red error boxes.Release order: code → fragments → page; publish rights limited to release managers.
RolloutThe Translate app's rollout created market pages but didn't preview them (404); the variant swap didn't update alt text.Rollout config auto-previews; the variant mapping carries alt text.
IntegrationSAP's real registration form is a shared Form.io form with extra consents and channels our copy lacks; submit is stubbed.Decide embed-vs-API with the SAP forms team before building more events.
